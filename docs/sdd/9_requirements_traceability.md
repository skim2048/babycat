# 9. 요구사항 추적 (Requirements Traceability)

SRS의 각 요구사항이 이 문서의 어느 절에서 실현되는지 대응시킨다. 대응되지 않은 요구사항은 설계 누락이고, 대응되는 요구사항이 없는 설계는 근거 없는 설계다. 삭제된 식별자(`FR-011`·`FR-023`)는 표에 넣지 않는다. "수치 미정의"는 SRS가 수치 목표를 정의하지 않은 항목으로, 설계는 측정 지점만 제공한다.
